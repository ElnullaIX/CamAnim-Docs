# CamAnim Docs

Source of https://elnullaix.github.io/CamAnim-Docs/ (Docusaurus 3).

- `npm start` opens a live preview at http://localhost:3000/CamAnim-Docs/
- `npm run check` builds the site and checks it (broken links, old names, required pages)
- Pushing to `master` publishes the site through GitHub Actions
