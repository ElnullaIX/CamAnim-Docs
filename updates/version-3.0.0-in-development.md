CamAnim v3 is still being built and tested. **It is not released yet.** What you download from Gumroad today is v2.0.1.

v3 is in beta testing with a small group first. It brings:

- A smoother path that follows the curve between waypoints
- A rebuilt Orbit: circle, spiral or arc, around you or a spot you place, with Size, Height and Aim
- Pause and Speed 0 that really stop the camera
- Reverse at the same speed as forward
- Install with VRCFury or Modular Avatar

This post will be updated when v3 is ready.
